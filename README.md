## 📖 About this project

This repository hosts my **personal portfolio website**, published with **GitHub Pages** at
👉 **[dacongan.github.io](https://dacongan.github.io)**.

It's a fast, dependency-free, **single-page** site built with vanilla **HTML, CSS &amp; JavaScript** — no frameworks, no build step. It presents who I am, my academic path, my certifications, and how to reach me, all wrapped in a clean maritime-inspired design (deep navy `#0A2342`).

---

## ✨ Features

- 🌍 **Fully bilingual** — instant **EN / ES** language toggle across the whole site.
- 📱 **Responsive single-page design** — smooth navigation between sections.
- ⚓ **Maritime aesthetic** — deep-navy palette and clean typography that fit the naval architecture theme.
- 🎓 **Education timeline** — my academic journey from Physics (UMU) to Engineering (UPCT).
- 📜 **Certifications section** — verifiable complementary training (Ansys/ESSS, UIMP, Santander Open Academy, ESADE, IE University).
- 📝 **Course-material samples** — free previews of my own **LaTeX** notes, available for download.
- 🔗 **Academic profiles** — direct links to LinkedIn, ResearchGate, ORCID and Zenodo.
- ⚡ **Zero dependencies** — loads instantly, hosted entirely on GitHub Pages.

<details>
<summary><b>🚀 Run it locally</b></summary>

<br>

Since it's a fully static site, running it locally is as simple as:

```bash
# 1. Clone the repository
git clone https://github.com/Dacongan/Dacongan.github.io.git

# 2. Enter the folder
cd Dacongan.github.io

# 3. Open index.html in your browser  (or serve it locally)
python -m http.server 8000    # then visit http://localhost:8000
```

That's it — no installs, no dependencies. 🎉
